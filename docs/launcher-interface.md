# 시작.bat(원클릭 실행 파일)이 `kakao.cmd` 를 부를 때 알아야 할 규약

작성: 2026-11-13, 코드와 시험(414개 통과) 기준입니다. 이 문서는 **읽기 전용 안내**이고 `시작.bat` 자체는 건드리지 않았습니다(10월 28일 임시 화면 그대로). 정본은 코드와 시험이며, 달라지면 코드가 맞습니다.

## 부르는 방법

- `시작.bat` 이 쓰는 방식 그대로 씁니다: `pushd "%~dp0"` 로 이 폴더에 들어간 뒤 특수 글자가 없는 상대 경로 `call .\kakao.cmd <명령> ...`. 폴더 이름의 `^`·`%`·`&`·`!` 에서도 동작하도록 시험으로 고정돼 있습니다(`Bootstrap.Tests.ps1`).
- 결과는 **종료 코드로 판단**하세요(한글 문구를 읽어 판단하지 말 것). 문구는 바뀔 수 있습니다.
- `.bat`·`.cmd` 파일은 BOM 없이 CRLF 줄바꿈이어야 합니다(시험이 강제). 한글 출력은 `chcp 65001`.

## 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 정상 |
| 1 | 사용법 오류 또는 권한 없음(예: 사람 전용 작업을 사람이 아닌 방식으로 부름, 허용 목록에 없는 방) |
| 2 | 안전장치가 입력 전에 멈춤(포그라운드 아님, 실행 잠금 이미 있음, 같은 시도 번호 재사용, 보내기 결과 불명 등) |
| 3 | 환경 문제(보내기 잠김, 내보내기 파일 없음, 설정 파일 손상 등) |
| 4 | 시험해 본 적 없는 카카오톡 버전이라 보내기 잠김 |

## 지금 연결된 명령

| 명령 | 상태 | 비고 |
|---|---|---|
| `version` | 동작 | 키트 버전 |
| `status` | 동작(최소판) | 버전, 보내기 모드, 허용 방 수. 읽기만 함 |
| `rooms list` | 동작 | 누구나 |
| `rooms add\|remove\|set ... --human` | 동작 | **사람만**: `--human` 이 있고 키보드 입력이 막혀 있지 않아야 함 |
| `read <방> [--since 7d\|12h] [--last N] [--human]` | 연결됨 | 보관된 내보내기가 있어야 함(없으면 종료 코드 3). `export` 는 아직 없음 |
| `search <낱말> [--room <방>] [--human]` | 연결됨 | 같은 조건 |
| `send --room <방> (--text <글> \| --file <파일>) [--dry-run] [--yes] [--attempt-id <번호>] [--human]` | **잠김** | 어떤 호출도 종료 코드 3(입력란 위치 미측정). 메뉴에 "보내기"를 넣어도 지금은 실제로 보내지 못함 |
| `help`, `export`, `open`, `update`, `uninstall`, 번호 메뉴 | 없음 | ⏳ 11·12단계 |

## 메뉴를 만들 때 지켜야 할 것

1. **`--human` 은 키보드 앞의 사람일 때만 통합니다.** 입력을 파이프(`|`)나 `<` 로 넣으면 거절됩니다(종료 코드 1). 메뉴에서 사람이 직접 고른 `rooms add` 등에만 붙이세요. 자동 실행에서 붙이면 거절되는 것이 정상입니다.
2. **사용자가 입력한 글자를 따옴표 없이 `kakao.cmd` 에 넘기지 마세요.** 따옴표 없는 `&` 가 있으면 cmd 가 그 뒤를 별도 명령으로 실행합니다(알려진 한계 D-07, 시험으로 고정). 메시지 본문은 `--text` 대신 파일에 써서 `--file` 로 넘기는 편이 안전합니다(`--` 로 시작하는 글도 보낼 수 있음). 방 이름·낱말도 큰따옴표로 감싸세요.
3. **보내기는 두 번 확인하세요.** `--dry-run`(미리보기) 뒤에 사람이 확인하고 `--yes` 로 보냅니다. AI 가 부를 때는 `--attempt-id` 가 필수입니다. 보내기가 열린 뒤에도 같은 시도 번호로 다시 보낼 수 없고, 결과가 "불명"(종료 코드 2)이면 방에서 직접 확인하기 전에는 다시 보내지 말라고 안내해야 합니다.
4. **카카오톡 창을 키트가 맨 앞으로 만들지 못합니다.** 입력이 필요한 단계(방 열기·보내기가 열린 뒤)에서는 "카카오톡 창을 한 번 클릭하고 손을 떼세요"를 안내하세요(설계서 13.8). 대기 부품 `Foreground.ps1` 은 만들었지만 아직 흐름에 끼우지 않았습니다.
5. **작업 중에는 키보드·마우스를 만지지 않도록 안내하세요.** 만지면 안전장치가 멈춥니다(종료 코드 2).
6. **동의 화면은 메뉴 쪽 몫입니다.** 동의 저장 함수(`Set-KitConsent`)와 확인 함수(`Assert-KitReady`)는 있지만 아직 어떤 명령도 동의를 요구하지 않습니다.
